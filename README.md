
# Microsoft 365 Security Baseline Assessments & Remediation

## Project Overview

This project documents my hands-on experience assessing and remediating Microsoft 365 security configurations during an IT Support / Cybersecurity internship at a Managed Service Provider (MSP).

The work focused on identifying security misconfigurations, reviewing administrative settings, and implementing corrective actions.

## Troubleshooting Process

1. Identify a failed security baseline check.
2. Review the security finding and recommended configuration.
3. Navigate to the appropriate Microsoft 365 or Entra ID administrative settings.
4. Apply authorized corrective changes.
5. Review the configuration to confirm the intended settings.
6. Document the remediation.
